**Odin Recipes**

This is my first project from [The Odin Project](https://www.theodinproject.com/).

The goal of this project was to practice the basic HTML concepts I learned in the Foundations course by creating a simple recipe website.

The website includes a main page with links to three different recipes:

- World’s Best Lasagna
- Disney’s Ratatouille
- Rich and Simple French Onion Soup

Each recipe page contains an image, a short description, a list of ingredients, and step-by-step cooking instructions.

**Skills Used**

During this project, I practiced:

- Creating basic HTML pages
- Using HTML boilerplate
- Working with headings and paragraphs
- Creating ordered and unordered lists
- Adding images with relative file paths
- Creating links between multiple HTML pages
- Organizing files into directories
- Using Git and GitHub for version control
